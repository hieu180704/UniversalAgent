# 1. Mục Tiêu & Định Nghĩa Cốt Lõi

- Tên phân hệ: Installer — cầu nối giữa repo UniversalAgent (bộ cài) và dự án đích.
- Mục đích tồn tại: Đưa toàn bộ khung 3 Engine AI độc lập sang một dự án bất kỳ mà không phá hỏng cấu hình đã có sẵn, và chạy lại được nhiều lần (idempotent).
- Các bản installer:
  - `start.bat`: Trình cài đặt 1-Click / Kéo & Thả trên Windows Explorer.
  - `install.ps1`: Trình cài đặt PowerShell tương tác trên Windows.
  - `install.sh`: Trình cài đặt Bash trên macOS & Linux.

Nguyên tắc chi phối:

    Dự án đích luôn đúng. Khi có xung đột, khung nhường — không ghi đè cấu hình riêng.

# 2. Quy Chuẩn & Thiết Lập Nền Tảng

Bốn nhóm file và quy chuẩn xử lý:

  Nhóm 1 — KHUNG SỞ HỮU, luôn cập nhật
    `.agents/`, `.claude/`, `.codex/`
    Sao chép đầy đủ bằng file thật vào dự án đích (không dùng symlinks hay junctions).

  Nhóm 2 — DỰ ÁN ĐÍCH SỞ HỮU, không ghi đè nếu đã tồn tại
    `.editorconfig`, `.gitignore`, `.gitattributes`

  Nhóm 3 — SEED MỘT LẦN (KHÔNG COPY FILE TEMPLATE SANG)
    `AGENTS.md`, `CLAUDE.md`
    Chỉ tạo từ template khi dự án đích chưa có file tương ứng. Tuyệt đối không sao chép `AGENTS_TEMPLATE.md` hay `CLAUDE_TEMPLATE.md` sang dự án đích.

  Nhóm 4 — DOCS KHUNG
    Dựng cấu trúc thư mục con trong `Docs/` và sao chép tri thức nền.

# 3. Danh Mục Thực Thể & Trình Tự Cài Đặt

Trình tự các bước thực hiện:

  1. Kiểm tra và tạo thư mục đích nếu chưa tồn tại.
  2. Chặn tự cài đè lên chính thư mục nguồn của framework.
  3. Sao chép các thư mục `.agents`, `.claude`, `.codex`, `Docs`.
  4. Sao chép các tệp cấu hình gốc (`.editorconfig`, `.gitignore`, `.gitattributes`).
  5. Khởi tạo `AGENTS.md` và `CLAUDE.md` từ template nếu chưa có (không copy file template sang đích).
  6. Hoàn tất cài đặt ngay lập tức (100% tệp tin thật, không cần tạo liên kết trung gian).

---

# 4. Bẫy Ngầm Đã Gặp & Cách Phòng Ngừa

  Cài đè lên chính thư mục nguồn
    Phòng: So sánh đường dẫn nguồn và đích, huỷ cài đặt nếu trùng nhau.

  Rác file template ở dự án đích
    Phòng: Chỉ dùng template để sinh ra `AGENTS.md` và `CLAUDE.md`, loại bỏ template khỏi danh sách sao chép tệp.

  Xung đột Junctions / Phân quyền trên Windows
    Phòng: Bỏ hoàn toàn cơ chế Junctions và lõi `.ai/`. Mỗi engine giữ file thực tế riêng, cài đặt bằng copy thuần túy.
