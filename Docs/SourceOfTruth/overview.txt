# 1. Định Danh & Mục Tiêu Dự Án

- Tên: UniversalAgent
- Lĩnh vực: Bộ khung vận hành (operating framework) tiêu chuẩn hóa cho AI Agent.
- Bản chất: Starter kit phân phối qua installer. Thư mục repo đóng vai trò BỘ CÀI, giữ cố định một chỗ trên máy rồi cài đặt cho nhiều dự án đích khác nhau.
- Phạm vi nền tảng: Hỗ trợ song song 3 nền tảng AI Agent hàng đầu:
  1. Antigravity IDE (Gemini) qua `.agents/`
  2. Claude Code qua `.claude/`
  3. Codex CLI qua `.codex/`
- Techstack: Node.js thuần (không external dependencies, không package.json), PowerShell + Batch + Bash cho installer.

---

# 2. Bài Toán Cốt Lõi Đang Giải

Khi làm việc cặp với AI Agent qua nhiều nền tảng, việc sao chép thủ công các quy tắc, kỹ năng, hooks và tài liệu sống dẫn đến trôi lệch (drift) và bảo trì tốn kém. Mặt khác, các engine AI có cú pháp nạp quy chuẩn (Rules Frontmatter), I/O contract của Hooks và định dạng Subagent hoàn toàn khác nhau.

UniversalAgent giải quyết bài toán đó bằng mô hình:

    3 ENGINE ĐỘC LẬP — TÁCH BIỆT NGUYÊN BẢN CHO TỪNG ENGINE — ĐỒNG BỘ QUA KỸ NĂNG /sync-engines.

Mỗi engine giữ bản rule, hook, agent và recipe riêng bằng file thật, không phụ thuộc lõi trung gian hay symlinks/junctions dễ gãy. Khi có thay đổi tri thức, kỹ năng `/sync-engines` tự động chuyển đổi chuẩn hóa cú pháp cho 2 engine còn lại.

# 3. Kiến Trúc 3 Engine Độc Lập

Mỗi engine được tổ chức thành một thư mục riêng biệt, 100% tệp tin thực tế:

    .agents/            Thư mục chuyên biệt cho Antigravity IDE (Gemini)
                        ├── rules/      Rules với frontmatter `trigger: always_on` hoặc `trigger: glob`
                        ├── recipes/    Các mẫu cấu trúc đầu ra (1-1 copy)
                        ├── skills/     Kỹ năng agent (/init, /newsession, /wrap, /sync-engines)
                        ├── agents/     Subagents định dạng Markdown (model: pro/flash)
                        ├── hooks/      Mã nguồn Hooks riêng biệt (hook-adapter.js chuyên cho Antigravity)
                        └── hooks.json  Cấu hình đăng ký Hooks theo schema Antigravity

    .claude/            Thư mục chuyên biệt cho Claude Code
                        ├── rules/      Rules với frontmatter `description:` và `paths:` (list)
                        ├── recipes/    Các mẫu cấu trúc đầu ra (1-1 copy)
                        ├── skills/     Kỹ năng agent (/init, /newsession, /wrap, /sync-engines)
                        ├── agents/     Subagents định dạng Markdown (model: opus/sonnet)
                        ├── hooks/      Mã nguồn Hooks riêng biệt (hook-adapter.js chuyên cho Claude)
                        └── settings.json Cấu hình đăng ký Hooks và Permissions

    .codex/             Thư mục chuyên biệt cho Codex CLI
                        ├── rules/      Rules dạng Markdown thuần không frontmatter
                        ├── recipes/    Các mẫu cấu trúc đầu ra (1-1 copy)
                        ├── agents/     Subagents định dạng TOML (developer_instructions inline)
                        ├── hooks/      Mã nguồn Hooks riêng biệt (hook-adapter.js chuyên cho Codex)
                        └── hooks.json  Cấu hình đăng ký Hooks theo schema Codex

    AGENTS.md           Hướng dẫn khởi đầu và bản đồ chỉ mục cho Antigravity & Codex
    CLAUDE.md           Hướng dẫn khởi đầu và bản đồ chỉ mục cho Claude Code

# 4. Lớp Guardrail & Lifecycle Hooks

Mỗi engine sở hữu bản `hook-adapter.js` riêng biệt để xử lý đúng chuẩn I/O contract:
- **Antigravity:** STDOUT JSON (`decision: allow/deny/ask`), payload lồng trong `toolCall`, exit 0.
- **Claude Code:** Chặn bằng STDERR + exit 2, hỏi quyền bằng STDOUT `permissionDecision='ask'`.
- **Codex CLI:** Bóc tách lệnh `apply_patch`, STDOUT JSON `permissionDecision`, lưu trust theo hash file.

Các hook chức năng dùng chung:
- `safety-guard.js`: Chặn thao tác trực tiếp trên file nhạy cảm (.env, *.pem, id_rsa*, credentials.json, secrets/) và lệnh huỷ diệt diện rộng.
- `read-guard.js`: Cảnh báo (advisory) khi đọc file nhị phân/media lớn tránh lãng phí token context.
- `closeout-trigger.js`: Nhắc cập nhật Living Docs trong Docs/ trước khi thực hiện `git commit` và cảnh báo `/sync-engines` khi sửa file AI.
- `doc-budget.js`: Cưỡng chế ngân sách độ dài tài liệu theo cơ chế ratchet và kiểm tra khai báo hook registry.
- `language-guard.js`: Đảm bảo văn xuôi trong tài liệu viết bằng tiếng Việt có dấu (≥90%).

# 5. Cơ Chế Đồng Bộ Đa Engine (/sync-engines)

Khi có bất kỳ chỉnh sửa nào về Rules, Recipes, Skills hoặc Subagents:
- Kỹ năng `/sync-engines` (thực thi qua `.agents/skills/sync-engines/scripts/sync-engines.js`) tự động chuyển đổi Frontmatter, TOML và model tiers, bảo toàn 100% nội dung logic.
- Không phát sinh drift, không cần bảo trì thủ công ở 3 nơi.

# 6. Quy Ước Sở Hữu File & Installer

- **Khung sở hữu:** `.agents/`, `.claude/`, `.codex/`, `AGENTS_TEMPLATE.md`, `CLAUDE_TEMPLATE.md`
- **Dự án đích sở hữu:** `.editorconfig`, `.gitignore`, `.gitattributes`
- **Seed khởi đầu:** `AGENTS.md`, `CLAUDE.md` (sinh ra trực tiếp từ template khi cài đặt, không mang template sang dự án đích).
- **Bộ cài đặt:** `start.bat` / `setup.bat` (Windows), `install.ps1` (PowerShell), `install.sh` (Unix). Sao chép trực tiếp các thư mục engine bằng file thật, không dùng junctions hay symlinks.

---

# 7. Ràng Buộc Bất Di Bất Dịch

1. Không thêm external dependency. Hooks và scripts phải chạy được bằng Node.js thuần.
2. Quy trình 4 pha bắt buộc: `explore -> propose -> confirm -> execute`.
3. Sửa tận gốc (Root-Cause & First-Principles), không che giấu lỗi bằng null-check mù quáng.
4. Living Docs là nguồn chân lý duy nhất (Single Source of Truth), luôn đồng hành cùng mã nguồn.
