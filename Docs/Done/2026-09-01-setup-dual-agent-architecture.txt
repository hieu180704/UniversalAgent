# 2. Chi Tiết Thay Đổi
- **Lõi trung lập `.ai/`:**
  - Khởi tạo `.ai/hooks/` với bộ Universal Hooks (`hook-adapter.js`, `safety-guard.js`, `read-guard.js`, `closeout-trigger.js`, `doc-budget.js`).
  - Khởi tạo `.ai/recipes/` với 7 recipe chuẩn (`00-recipe-index.md`, `recipe-analysis.md`, `recipe-decision-memo.md`, `recipe-deliverable.md`, `recipe-plan.md`, `recipe-review-qc.md`, `recipe-synthesis.md`).
  - Khởi tạo `.ai/rules/` với 4 universal rules (`core-protocol.md`, `doc-policy.md`, `knowledge-graph.md`, `quality-standards.md`).
  - Khởi tạo `.ai/skills/` với các Agent Skills cốt lõi (`init`, `newsession`, `wrap`).
  - Khởi tạo `.ai/setup-links.js` quản lý liên kết Directory Junctions và Symlinks đa nền tảng.
- **Cấu hình Adapters `.agents/` & `.claude/`:**
  - Cập nhật `.agents/hooks.json` và `.agents/skills.json`.
  - Cập nhật `.claude/settings.json`.
  - Thiết lập Directory Junctions `.agents/rules`, `.agents/skills`, `.claude/rules`, `.claude/skills` nối tới `.ai/`.
- **Dọn dẹp tệp tin & nền tảng cũ:**
  - Xóa bỏ `.openai/`, `.github/`, `.cursorrules`, `CHATGPT.md`, `CHATGPT_TEMPLATE.md`, `scripts/sync-agents.js`.
  - Xóa các thư mục lệnh/recipes/hooks phân mảnh cũ trong `.agents/` và `.claude/`.
- **Entry Points & Trình cài đặt:**
  - Cập nhật `AGENTS.md`, `AGENTS_TEMPLATE.md`, `CLAUDE.md`, `CLAUDE_TEMPLATE.md`.
  - Viết lại toàn diện `README.md`.
  - Nâng cấp `install.ps1`, `install.sh`, `setup.bat` tự động sao chép thư mục `.ai`, `.agents`, `.claude`, `Docs` và kích hoạt Directory Junctions.
