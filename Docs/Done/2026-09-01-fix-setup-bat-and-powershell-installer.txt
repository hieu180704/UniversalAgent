# 1. Tóm Tắt Công Việc
- **Mục tiêu:** Sửa dứt điểm lỗi cú pháp CMD batch trong `setup.bat` khi khởi chạy hoặc kéo thả, chuẩn hóa encoding UTF-8 có BOM cho `install.ps1` và bổ sung cơ chế fallback tạo Junctions native.
- **Thời gian hoàn thành:** 2026-09-01

---

# 2. Chi Tiết Thay Đổi
- **`setup.bat`:**
  - Kích hoạt `setlocal EnableDelayedExpansion` để xử lý chuỗi runtime, xóa bỏ lỗi parse-time token của CMD.
  - Phân nhánh truyền tham số rõ ràng: Nếu có tham số truyền `-TargetDir "!TARGET!"`, nếu không thì gọi interactive mode `install.ps1`.
- **`install.ps1`:**
  - Thêm UTF-8 BOM chống vỡ parser PowerShell 5.1 khi đọc ký tự tiếng Việt.
  - Thêm `TrimEnd('\', '/')` tự động dọn sạch ký tự gạch chéo cuối.
  - Thêm cơ chế fallback tạo Directory Junctions bằng native `cmd /c mklink /J` khi môi trường chưa cài Node.js.
